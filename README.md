# e-plantShopping

## 🌿 Project Overview
e-plantShopping is a React-based e-commerce application for selling indoor and outdoor plants.  
It allows users to browse products, add plants to a shopping cart, and manage quantities dynamically using Redux Toolkit.

## 🚀 Features
- Landing page with "Get Started" button
- Product listing with categories
- Shopping cart functionality
- Increase / decrease quantity
- Remove items from cart
- Total price calculation

## 🛠 Tech Stack
- React
- Redux Toolkit
- React Router
- CSS

## 📦 Pages
- Home (Landing Page)
- About Us
- Products
- Cart

## 💡 Purpose
This project demonstrates state management using Redux and building a full shopping experience in React.
